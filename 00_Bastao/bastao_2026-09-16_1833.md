# ANEXO: o procedimento de instalação, na íntegra

O Fred autorizou executar. Rode, mostre a ele o que mudou, e diga como desfazer.

## Caminho A: os arquivos já estão em ~/Downloads

```
mkdir -p ~/.claude/skills/bastao/bin ~/.claude/skills/bastao/references
cp ~/Downloads/SKILL.md              ~/.claude/skills/bastao/
cp ~/Downloads/bastao.py             ~/.claude/skills/bastao/bin/
cp ~/Downloads/MODELO_bastao.md      ~/.claude/skills/bastao/references/
cp ~/Downloads/instalacao-hooks.md   ~/.claude/skills/bastao/references/
chmod +x ~/.claude/skills/bastao/bin/bastao.py
```

## Caminho B: buscar do repositório

```
cd ~/Downloads
git clone --branch claude/skills-handoff-analysis-7jxsa6 \
  https://github.com/aeioufred-rgb/monitor-municipio-uniao.git _bastao_tmp
mkdir -p ~/.claude/skills
cp -R _bastao_tmp/skills/bastao ~/.claude/skills/
chmod +x ~/.claude/skills/bastao/bin/bastao.py
```

A pasta `_bastao_tmp` depois vai para quarentena datada, não para o `rm`.

## Conferir que a estrutura ficou certa

```
find ~/.claude/skills/bastao -type f | sort
```

Tem que sair exatamente isto:

```
/Users/<usuario>/.claude/skills/bastao/SKILL.md
/Users/<usuario>/.claude/skills/bastao/bin/bastao.py
/Users/<usuario>/.claude/skills/bastao/references/MODELO_bastao.md
/Users/<usuario>/.claude/skills/bastao/references/instalacao-hooks.md
```

**Neste ponto a skill já funciona**, pelos gatilhos verbais da description. Os passos abaixo
acrescentam os hooks, que são o que percebe a hora por ele.

## Ligar os hooks

1. Backup primeiro, sem exceção:

```
cp ~/.claude/settings.json ~/.claude/settings.json.bak_$(date +%Y-%m-%d)
```

Se o arquivo não existir ainda, criar com `{}` dentro.

2. Pegar o bloco pronto, já com o caminho absoluto resolvido:

```
python3 ~/.claude/skills/bastao/bin/bastao.py settings
```

3. Juntar o bloco `hooks` ao `settings.json`, **acrescentando** aos eventos que já existirem,
   sem apagar nada. Usar a skill `update-config`, que é a própria para isso.

4. Conferir que o JSON continua válido:

```
python3 -m json.tool ~/.claude/settings.json > /dev/null && echo "JSON valido"
```

## Teste de fumaça

```
cd /tmp && echo "{\"session_id\":\"teste\",\"transcript_path\":\"/etc/hosts\",\"cwd\":\"$PWD\"}" \
  | python3 ~/.claude/skills/bastao/bin/bastao.py hook-stop; echo "rc=$?"
```

Esperado: saída vazia e `rc=0`. Vazio está certo, porque `/etc/hosts` é pequeno e fica abaixo
do limiar.

Depois, num caso real do Fred, com ele junto:

```
cd ~/Downloads/Bet/Casos/<algum caso>
python3 ~/.claude/skills/bastao/bin/bastao.py localizar
```

Esperado: ele imprime a raiz do caso, rotula o contexto como "bets e ludopatia" e monta o caminho
do arquivo em `00_Bastao/`. **É aqui que se confere a decisão pendente 1**: olhar a árvore do caso
e ver se `00_Bastao` conflita com alguma coisa.

## Como desfazer, se ele não gostar

- Tirar o bloco `hooks` do `settings.json`, ou restaurar o backup `.bak_AAAA-MM-DD`.
- A pasta `~/.claude/skills/bastao/` vai para quarentena datada, não para o `rm`.
- Nada mais depende da skill.

## Depois de instalar

Dizer a ele, em uma linha, que dá para usar assim:

- `/bastao` para gravar
- "vamos parar por aqui" ou "continuo amanhã" também disparam sozinho
- "retoma de onde paramos" para ler o bastão pendente da pasta
